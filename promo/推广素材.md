## 四、维护

- 生成激活码：Supabase → SQL Editor 执行 `select * from generate_codes(500);`，结果复制到闲鱼「自动发货」卡密库。每个码只能激活一台设备
- 买家换手机要重新激活：Table Editor → `activation_codes` 找到他的码，把 `devices` 改成 `{}`；或者执行 `update activation_codes set max_devices = 2 where code = '他的码';`
- 作废某个码（例如退款）：`update activation_codes set revoked = true where code = '那个码';`，买家下次打开网页就会失效
- 查看卖出 / 激活情况：`select count(*) filter (where first_used_at is not null) as 已激活, count(*) as 总数 from activation_codes;`
- 改价格 / 购买链接 / 收款码：编辑 `site/config.js`
